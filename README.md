# PT Segara Jaya Nusantara

Static company profile website for PT Segara Jaya Nusantara.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish with GitHub Pages

1. Create a GitHub repository for this site.
2. Push the website files to the `main` branch.
3. In the repository, open **Settings > Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The site uses plain HTML, CSS, JavaScript, and local media assets. No build step is required.
